# loja-do-bairro - Kanban
## Regra de WIP

O limite de WIP da coluna In Progress é de 3 tarefas simultâneas.

Quando o limite for atingido, nenhuma nova tarefa deverá ser iniciada até que uma das tarefas em andamento seja concluída ou movida para outra etapa.

A equipe deverá priorizar a finalização das tarefas existentes para evitar acúmulo de atividades e gargalos no fluxo de trabalho.
